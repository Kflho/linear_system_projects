实验五设计计算（观测器设计，磁盘驱动器磁头模型）
================================================================

对象: x' = [[0,1],[0,-1]] x + [0;1] u,  y = [1 0] x
能观性 rank = 2（n = 2，能观）
状态反馈: u = K x, K = [-5. -3.]  ->  eig(A+BK) = [-2.-1.j -2.+1.j]

[任务一] 全维观测器：F = A + LC, G = -L, H = B
  布置极点 [(-5+2j), (-5-2j)]  ->  L = [ -9. -20.]
  F = [[ -9.   1.]  [-20.  -1.]]
  G = [ 9. 20.], H = [0. 1.]
  eig(F) = [-5.-2.j -5.+2.j]
  闭环(分离)极点 = [-5.-2.j -5.+2.j -2.-1.j -2.+1.j]

[任务二] 降维观测器：z' = F z + G y + H u, x̂ = M z + N y
  误差极点 [-5.0]  ->  L21 = -4
  F = [[-5.]], G = [-20.], H = [1.]
  M = [0. 1.], N = [1. 4.]
  重构恒等式残差 |M L21 + N - C'(CC')^-1| = 0.00e+00
  闭环(分离)极点 = [-5.+0.j -2.-1.j -2.+1.j]

[任务三] 函数观测器：只重构 f = K x
  取 (F, G) = (-5, 1)  ->  T = [ 0.2  -0.05], H = T B = -0.05
  u = M_f z + N_f y = 60 z -17 y
  重构状态的增益 M = [  0. -20.], N = [1. 4.]（满足 M T + N C = I）
  M T + N C - I 残差 = 2.22e-16
  K (M z + N y) = [ 60. -17.]  与 M_f/N_f 一致
  闭环(分离)极点 = [-5.+0.j -2.-1.j -2.+1.j]

结论要点：
  * 三种观测器都满足分离原理：闭环极点 = {-2±j} ∪ 观测器极点。
  * (二)(三) 的闭环极点相同（都含 -5），u(t) 轨迹也完全相同；
    差别只是观测器内部状态 z 的标度（z_三 = -z_二 / 20）。
  * 全维观测器 x̂(0)=0，误差 e(0)=x0；降维/函数观测器 x̂1=y 直接可得，
    所以只有速度估计有初始误差。
