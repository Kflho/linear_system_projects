实验六设计计算（降维观测器 + 内模原理的渐近跟踪）
==================================================================

对象: x' = [[0,1],[0,-1]] x + [0;1] u,  y = [1 0] x
参考: r'' = -1^2 r  ->  r(t) = sin(1 t)（外系统 w' = A_r w）
内模: eta' = A_c eta + B_c e,  A_c = [[0,-1],[1,0]], B_c = [1;0]

[1] 增广系统极点配置（状态 + 内模）
  期望极点 [(-2+1j), (-2-1j), (-1+1j), (-1-1j)]
  能控 rank = 4 / 4
  K_aug = [-14.  -5. -12.   4.]
     K_x   = [-14.  -5.]
     K_eta = [-12.   4.]（kyita1 = -12 乘 eta1，kyita2 = 4 乘 eta2）
  增广闭环极点 = [-2.-1.j -2.+1.j -1.-1.j -1.+1.j]

[2] 降维观测器（与实验五任务二相同）
  误差极点 [-5.0]  ->  F = -5, G = -20, H = 1
  M = [0. 1.], N = [1. 4.]

[3] 闭环（含参考外系统）
  eig(A_cl) = [-5.+0.j -2.-1.j -2.+1.j -1.-1.j -1.+1.j  0.-1.j  0.+1.j]
  = 状态反馈 {-2±j} ∪ 内模 {-1±j} ∪ 观测器 {-5} ∪ 参考外系统 {±j}
  从 r 到 e 的闭环传递函数：|e/r(j omega0)| = 3.47e-16（内模原理要求 0），全频段 min|e/r| = 4.91e-03

[4] 内模控制器
  C_im(s) = K_eta (sI - A_c)^(-1) B_c = (-12 s + 4) / (s^2 + 1)
  omega = 1 处增益无穷大（分子在 s = ±1j 处不为零）
