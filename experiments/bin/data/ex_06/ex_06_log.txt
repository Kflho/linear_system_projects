================ 实验六 观测器 + 状态反馈：内模渐近跟踪 ================
【对象】x' = A x + B u,  y = c x = [1 0] x
  A = [0 1;0 -1],  B = [0;1]

【参考】r' = -1^2 r  ->  r(t) = sin(1 t)
  外系统 A_r = [0 1;-1 0],  C_r = [1 0],  w(0) = [0 1]

【内模】eta' = A_c eta + B_c e,  e = y - r
  A_c = [0 -1;1 0],  B_c = [1;0],  eta(0) = [0 0]
  即 eta1' = e - eta2,  eta2' = eta1     （特征多项式 s^2 + 1）

【增广系统极点配置】[x; eta] 共 4 阶
  能控 rank = 4 / 4
  K_aug = [K_x, K_eta] = [-14 -5 -12 4]
     K_x = [-14 -5]（乘 x̂）
     K_eta = [kyita1, kyita2] = [-12 4]（kyita1 乘 eta1、kyita2 乘 eta2）
  eig(A_aug + B_aug K_aug) = [-1-1i;-1+1i;-2-1i;-2+1i]
  （状态反馈那对 -2±j + 内模那对 -1±j）

【降维观测器】F = -5, G = -20, H = 1, M = [0 1], N = [1 4]
  误差极点 = -5

【闭环】状态 [x; z_obs; eta; w] 共 7 维
  eig(A_cl) = [0-1i;0+1i;-1-1i;-1+1i;-2-1i;-2+1i;-5]
  分离原理 + 内模 + 外系统：{-2±j} ∪ {-1±j} ∪ {-5} ∪ {±j}

【仿真】Tf = 20 s（约 3.2 个参考周期），采样 3001 点
  x(0) = [1 0],  x̂(0) = [1; 4]（z(0) = 0）
  u(0) = -34.00，max|u| = 34.00
  max|e| 全程 = 1.000e+00，末 5 s = 5.200e-07（内模原理：e -> 0）
  max|y - r| 末 5 s = 5.200e-07，max|y| = 1.000，max|r| = 1.000
  末段 x̂ 与 x 的最大偏差 = 6.439e-15（观测器误差 e^{-5t} 早已衰减）
  内模状态末段幅值：max|eta1| = 1.132，max|eta2| = 1.132（自己"长"出 1 rad/s 的振荡）

  末段幅值比 max|y|/max|r| = 1.0000（1 表示幅值无差）
【频域】内模控制器 C_im(s) = (-12 s +4)/(s^2 +1)
  |C_im(j1)| -> 无穷（分母为零、分子不为零）
  闭环 |e/r(j1)| = 3.47e-16（应为 0，即该频率上完全跟踪）
  闭环 |y/r(j1)| = 1.0000（应为 1）
