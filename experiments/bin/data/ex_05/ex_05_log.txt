================ 实验五 观测器设计（磁盘驱动器磁头）================
【对象】x' = A x + B u,  y = c x = [1 0] x
  A = [0 1;0 -1],  B = [0;1]
  开环极点 = [-1;0]（积分器 + 一阶惯性，磁头位置自身会漂）

【状态反馈】u = K x̂ 中的 K（先用真状态设计，再换成估计值）
  K = [-5 -3]
  eig(A + B K) = [-2-1i;-2+1i]

【(一) 全维观测器】F = A + L C, G = -L, H = B
  L = [-9;-20]
  F = [-9 1;-20 -1]
  eig(F) = [-5-2i;-5+2i]
  eig(A_cl) = [-2-1i;-2+1i;-5-2i;-5+2i]
  （分离原理：闭环极点 = 状态反馈极点 ∪ 观测器极点）

【(二) 降维观测器】z' = F z + G y + H u,  x̂ = M z + N y
  L21 = -4,  F = -5,  G = -20,  H = 1
  M = [0 1],  N = [1 4]
  eig(F) = -5,  eig(A_cl) = [-2-1i;-2+1i;-5]

【(三) 函数观测器】只重构 f = K x
  (F, G) = (-5, 1),  T = [0.2 -0.05],  H = T B = -0.05
  控制律直接写：u = M_f z + N_f y = 60 z -17 y
  模型里画估计状态用的 M = [0 -20], N = [1 4]（满足 M T + N C = I）
  eig(A_cl) = [-2-1i;-2+1i;-5]

【(一) 仿真】Tf = 8 s，采样 3001 点
  x̂(0) = 0，估计误差 e(0) = x(0) = [1 0]
  max|u| = 6.270，max|e| = 1.434，e 衰减到 2% 用时 1.18 s，末段 max|e| = 3.50e-16

【(二) 仿真】z(0) = 0 -> x̂(0) = [1; 4]（x̂1 = y 直接量到，只有速度有初差）
  max|u| = 17.000，max|e| = 4.000，e 衰减到 2% 用时 0.78 s，末段 max|e| = 2.06e-16

【(三) 仿真】u = M_f z + N_f y = 60 z -17 y
  max|u| = 17.000，max|e| = 4.000，e 衰减到 2% 用时 0.78 s，末段 max|e| = 2.06e-16
  模型里 x̂→K 与直接 M_f z + N_f y 的差 = 5.33e-15（数值一致）
  函数观测器内部状态 z3 与降维观测器 z2 的关系：max|z3 + z2/20| = 3.01e-16
  -> 同一条闭环（误差极点都是 -5），只是 z 的坐标标度不同，u(t) 完全相同

  max|u_(三) - u_(二)| = 1.07e-14

【对比】
  观测器                    max|u|     max|e|    e 2% 时间       u(0)
  (一) 全维                  6.270      1.434       1.18      0.000
  (二) 降维                 17.000      4.000       0.78    -17.000
  (三) 函数                 17.000      4.000       0.78    -17.000
  （初值不同：全维 x̂(0)=0，降维/函数 x̂1(0)=y(0)，所以 u(0) 有差别）
