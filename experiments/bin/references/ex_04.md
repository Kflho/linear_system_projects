## 1. 实验目的

1. 掌握**内模原理**：不用测 $w$，只把外系统的特征多项式做进补偿器，就能无静差跟踪；
2. 会内模 + 增广系统的极点配置（$K_{aug}=[K_x,K_\eta]$）；
3. Simulink 复现两个任务，画 $r,y,x,u$。

## 2. 两个模型的接线（读 `.slx` 得到的实际结构）

### 2.1 任务一 `ex_04_1_sim.slx`

```
State-Space(A_v..)  w' = A_v w          （输入口空着，初值模型里写死 0 → 需覆盖）
   └─ Gain r [0.1 0] ── r ──┐
State-Space1(A..D, C=I4)     │
   └─ Gain c [1 0 0 0] ── y ─┤
                             Sum '|-+'   e = y - r
                                └─ Sum1 '|++'  a' = e + w·b      (w = -4)
                                     └─ Integrator  a
                                          ├─ Integrator1  b            (b' = a)
                                          ├─ Gain kyita2 ─┐
                                          └─ Gain kyita1 ─┤
Gain k_x [1 0 0 0] 形式的 1x4 ─────────────────────────── Sum2 '|+++' ── u
```

要点：
- 内模反馈 $-4$ 取自 **b**（第二级积分输出）回到 **a'** 的求和：$a'=e-4b,\;b'=a$，特征多项式 $s^2+4$ ✓
- 控制增益顺序是 $[k_x(4),\;k_{\eta2}\text{(对 }a),\;k_{\eta1}\text{(对 }b)]$

### 2.2 任务二 `ex_04_2_sim.slx`

对象在模型里**用积分链搭**（不是 State-Space）：

$$
x_1' = d + x_2,\qquad x_2' = 2d + u -2x_1 + 2x_2
$$

即 `Sum4 '|++'` → $x_1'$（$d$ 直接进，权重 1），`Sum3 '|++++'` → $x_2'$
（`gain1 = 2` 乘 $d$、`gain2 = -2` 乘 $x_1$、`gain7 = 2` 乘 $x_2$），合起来 $E=[1;2]$。

内模是**三级积分链**：$p'=e-4q,\;q'=p,\;s'=q$，即

$$
\frac{q}{e}=\frac{1}{s^2+4},\qquad \frac{s}{e}=\frac{1}{s(s^2+4)}
$$

—— 一条链同时含 $1/(s^2+4)$（跟余弦）和 $1/s$（抗常值干扰），这正是"干扰 $d=1(t)$ + 参考 $\cos2t$"需要的最小内模（阶数 3）。

控制：`Sum2 '|+++++'` 求和 → $u=k_{\eta3}p+k_{\eta1}s+k_{x2}x_2+k_{x1}x_1+k_{\eta2}q$。

## 3. 设计方法

**内模原理**：把外系统（参考 + 干扰）的特征多项式 $\prod(s-\lambda_i)$ 做成补偿器

$$
\eta'=A_c\eta+B_c e,\qquad A_c=\text{companion}\big(\text{charpoly}(A_v,A_d)\big)
$$

再对增广系统

$$
\begin{bmatrix}x'\\\eta'\end{bmatrix}=
\underbrace{\begin{bmatrix}A&0\\B_cC&A_c\end{bmatrix}}_{A_{aug}}
\begin{bmatrix}x\\\eta\end{bmatrix}+
\underbrace{\begin{bmatrix}B\\0\end{bmatrix}}_{B_{aug}}u,\qquad
u=K_{aug}\begin{bmatrix}x\\\eta\end{bmatrix}
$$

做极点配置。$A_{aug}+B_{aug}K_{aug}$ 稳定 $\Rightarrow e\to0$。

**离线判据（不用仿真就能确认对不对）**：闭环传递

$$
\left|\frac{e}{r}(j2)\right|=0\quad(\text{跟 }\cos2t),\qquad
\left|\frac{e}{d}(0)\right|=0\quad(\text{抗常值})
$$

两个都是 $10^{-16}$ 量级，说明内模真的进了闭环。

> 手搭模型的 $A_c$ 方向和默认友矩阵不同（$[0,-4;1,0]$ vs $[0,1;-4,0]$），
> 所以 `cal_internal_model(..., Ac=..., Bc=...)` 直接把模型实际的矩阵传进去，
> 出来的 $K_\eta$ 才是模型坐标下的增益 —— 这点搞错会得到"极点对了但跟踪不上"的假象。

## 4. 仿真结果

任务一：$y$ 从 0 起步（$r(0)=0.1$，初始误差 0.1），约 2.5 s 贴住参考（最慢极点 $-2$，$5\tau=2.5$ s），
之后误差 $6\times10^{-11}$。控制 $u$ 只有 $\pm1.14$，但 $k_xx$ 与 $k_\eta\eta$ 各自都有 $10^2$ 量级 —— 又是一次大对消。

任务二：$d=1(t)$ 从 $t=0$ 起就作用，$y$ 先冲到 0.156 再压回参考；
$x_2$ 稳态被顶到 $-1$（因为 $\dot x_1=x_2+d$，$x_1$ 要跟参考，$x_2$ 必须抵掉 $d$），
末段误差 $9.0\times10^{-17}$。$u$ 峰值 6.1（$E=[1;2]$ 比原来的 $[1;1]$ 更猛一点）。

## 5. 踩过的坑（模型里都已修好）

1. ~~两个模型的参考发生器输入口都没接~~ → **已修**：两个模型都接了 `Constant 0`，
   现在模型能独立跑；`ex_04_*_run_sim.m` 里只做"输入口是否接上"的检查，不再打补丁。
2. ~~参考发生器初值写死成 `0`~~ → **已修**：初值改成变量 `v_start=[1;0]`（否则 $r\equiv0$，
   看起来"跟踪得很好"其实是参考恒零，这个最坑）。
3. ~~模型二里 $d$ 的两路注入共用 `gain1`（等效 $E=[1;1]$）~~ → **已修**：$x_1'$ 那路直接接 $d$，
   $x_2'$ 那路经 `gain1 = 2`，现在 $E=[1;2]$ 与任务书一致。改完 $K$ 不用重算（设计里 $E$ 不出现），
   但瞬态变猛一点：$u$ 峰值 $4.9\to6.1$、$\max|y|$ $0.151\to0.156$，末段误差 $1.9\to0.9\times10^{-16}$。
4. **内模的方向/取哪一级反馈**决定了 $A_c$，也决定增益顺序（$p,q,s$ 谁是导数谁是积分）。
   读模型时按"哪个积分器的输出进哪个增益"逐个对，别凭图猜。
5. 模型二的 `ktita2`、模型一的 `ktita2` 其实是 $e=y-r$ 的信号（名字像 $k_\eta$ 的笔误），
   仿真里我按"$e$"用；`x_x2_sim` 只是 $x_2$。

## 6. 和实验三的关系

| | 实验三（静态） | 实验四（内模） |
|---|---|---|
| 补偿器 | 无量测要求，$u=Kx+K_vw$，$w$ 必须**可测** | 只需要 $e$，$w$ 不可测也能跟 |
| 数学 | 调节器方程 $\Pi A_v=A\Pi+B\Gamma$，$K_v=\Gamma-K\Pi$ | $A_c$=外系统特征多项式，增广极点配置 |
| 抗扰 | 干扰要建模进外系统、并且**可测** | 常值/同频干扰只要进了内模就能压 |
| 增益量级 | $10^2$ | $10^3$（内模状态要"长"出振荡，增益偏大是正常的） |

## 7. 还可以再动的地方

- 极点还可以再往前放（比如 $[-3..-8]$），代价是 $|u|$ 和增益变大；现在这组是"够快又不过冲"的折中，最慢模态 $-2$ 对应 $\approx2.5$ s 收敛。
- 模型二如果想看 $E=[1;2]$ 对瞬态的影响，把 `gain1` 在 2 与 1 之间改一下重跑 `ex_04_main` 即可（其余都不用动）。
- 两个模型里的 `Constant 0` 可以换成 `Ground`（更省一个变量），不影响结果。
